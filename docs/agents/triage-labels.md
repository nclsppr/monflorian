# Labels de triage

Les skills utilisent cinq rôles canoniques. Ce tableau les associe aux labels du suivi GitHub.

| Rôle dans `mattpocock/skills` | Label GitHub | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Une personne responsable doit évaluer le ticket |
| `needs-info` | `needs-info` | Le ticket attend des précisions de son auteur |
| `ready-for-agent` | `ready-for-agent` | Le ticket est assez précis pour un agent autonome |
| `ready-for-human` | `ready-for-human` | Le ticket demande une intervention humaine |
| `wontfix` | `wontfix` | Le ticket ne sera pas traité |

Quand un skill cite un rôle, utiliser le label GitHub correspondant dans ce tableau. Modifier seulement la deuxième colonne si le dépôt adopte un autre vocabulaire.
